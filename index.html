Projects

Paint Drop Simulation

PaintDrops uses a marbling algorithm that distorts circles, as they are added, by continuously recalculating the vertices of a circle. The circles keep the same area, and never overlap each other. There is also several unique features such as a pattern generation, and a custom radius selection for the user to choose the size of the paint drop they want to draw.

Sonny Angel App

Feli's Angels is a Sonny Angel figurine simulation selling app. You can select the figurine, view your order with a summary of each item bought, its subtotal, the taxes, and the final price. Upon order confirmation, a thank you message will appear along with information like an order confirmation number, and the order date. A QR code is displayed in order to view the JSON, and the option to send the receipt to an email is present. You are also given the option to continue shopping afterwards, with a new order. The app is available in French and English.

Rotten Potatoes Movie Rating Site

Rotten Potatoes is an easy-to-use application that displays data about movies, including its ratings, and revenue. Furthermore, you can choose a specific country from a map, and it will display: How many movies were made there, The number of votes, The average movie rating for that country.
